Usage
=====

Usage
=====

Navigate to **Purchase > Orders > Purchase Orders**.

Open any purchase order that uses a currency different from the company currency.
The currency rate is displayed directly on the form, showing how many units of the
document currency equal one unit of the company currency on the order date.

No configuration is required beyond enabling multi-currency in
**Accounting > Configuration > Settings**.
